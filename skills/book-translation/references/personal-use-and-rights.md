# Personal use and rights boundary

Book Studio Core supports book-processing workflows only for **private,
personal, and non-commercial** use. The intended outcomes are a private copy
for the user's own reading, study, accessibility, or personal research.

## Allowed within this workflow

- Process a lawfully obtained source that the user is authorized to access.
- Keep the source, intermediate files, review artifacts, and final book in a
  private project directory controlled by that user.
- Read, annotate, study, or evaluate the private result for that user's own
  needs.
- Private local storage is allowed only as the technical means required for
  those personal activities. It must not become storage for other people or a
  collection intended for later publication or sharing.

## Not allowed within this workflow

Do not use a generated book, translation, localized image, or other derived
artifact to:

- sell, license, rent, or monetize it, including through client work, paid
  access, subscriptions, advertising, sponsorships, or donations tied to
  access;
- publish, upload, share, transfer, or redistribute it, in whole or in part;
- create or populate a shared archive, library, corpus, dataset, or service;
- provide copies to a team, class, organization, customer, audience, or other
  third party; or
- bypass DRM, access controls, contractual restrictions, or applicable law.

If a user asks for any of these actions, stop. Explain that release,
distribution, shared storage, and commercial use are outside this project's
default workflow. Do not upload or publish the artifact on the user's behalf.
Resume a commercial workflow only after both written permissions described
below have been independently verified.

## Software license versus book rights

The Book Studio Personal Use License applies to the software code in this
repository. It does not grant rights to any source book, reference edition,
translation, illustration, cover, localized asset, or generated book artifact.
Possessing a file or being able to process it does not establish permission to
reproduce, adapt, store for others, distribute, or commercialize it.

Commercial use requires two independent written permissions: a commercial
license from the Book Studio Core Licensor and binding authorization from every
applicable rights holder for the material being processed. Permission from a
book or product owner does not replace the software license, and permission
from the software Licensor does not replace third-party rights.

The user remains responsible for confirming the rights and permissions needed
for every input and output. This project policy does not provide legal advice.
If the rights position is unclear, keep the files private and stop before any
external transfer or release.
